## Coordinated disclosure

RIFTI follows coordinated disclosure. Vendors are notified before public release and given reasonable time to remediate. Advisories are published after a fix is available or after the disclosure window has elapsed.

To report a vulnerability in a RIFTI product or service, see our [Vulnerability Disclosure Policy](https://rifti.com.br).
